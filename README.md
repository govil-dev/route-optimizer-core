# NestJS DDD Monorepo

Este proyecto sigue una arquitectura DDD (Domain-Driven Design) y CQRS (Command Query Responsibility Segregation) implementada con NestJS y TypeScript. Está diseñado para ser modular y escalable, facilitando la gestión de múltiples Bounded Contexts.

## Estructura del Proyecto

La estructura de directorios está detallada en `documentation/ESTRUCTURA.md`.

## Configuración

Las variables de entorno se gestionan a través de archivos `.env`. Consulta `.env.example` para ver las variables requeridas.

## Instalación

```bash
npm install
```

## Ejecución

```bash
npm run start:dev
```

## Pruebas

```bash
npm run test
```
